# Your Phone Ringing

Godot 4 Android pixel-horror game. Target device: Huawei FIN-AL60 / HarmonyOS 4.2.

The Android workflow is configured in `.github/workflows/your-phone-ringing.yml` and expects the Godot project files in this directory, including `project.godot`, `main.gd`, `main.tscn`, `export_presets.cfg`, `art/`, and `audio/`.

**Status:** Build configuration committed; project assets and source files have not yet been uploaded to GitHub. No APK has been built or tested.
